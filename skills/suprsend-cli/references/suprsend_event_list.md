# suprsend event list

List events

List the events in a workspace: all of them unless --limit is given. Returns event names and their linked schema information.

```
suprsend event list [flags]
```

### Tips

- Use `-o json` for machine-readable JSON output, `-o yaml` for YAML. Default `-o pretty` outputs a human-friendly table.

### Options

```
  -h, --help            help for list
  -l, --limit int       Maximum number of events to return (default: all)
      --offset int      Number of events to skip for pagination
  -o, --output string   Output format: pretty, json, or yaml (default "pretty")
```
